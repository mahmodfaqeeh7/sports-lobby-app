DATABASE
Postgres runs through Docker Compose from:
backend/docker-compose.yml

Start database:
cd /Users/alfaqeh/Desktop/native/sports-lobby-app/sports-lobby-docs/backend
docker compose up -d postgres

Run migrations:
mvn flyway:migrate

Local data is stored in the Docker volume:
sports_lobby_postgres

GitHub does not move this database data. To move exact local data to another PC,
dump and restore the database manually:

On old machine:
cd /Users/alfaqeh/Desktop/native/sports-lobby-app/sports-lobby-docs/backend
docker compose exec postgres pg_dump -U sports_lobby -d sports_lobby > sports_lobby_dump.sql

On new machine:
docker compose up -d postgres
cat sports_lobby_dump.sql | docker compose exec -T postgres psql -U sports_lobby -d sports_lobby

ADMIN BOOTSTRAP
There is no public "create admin" endpoint, intentionally.
Admin is created through backend bootstrap configuration.

Environment variables:
SPORTS_LOBBY_ADMIN_BOOTSTRAP_ENABLED=true
SPORTS_LOBBY_ADMIN_EMAIL=admin@sports-lobby.local
SPORTS_LOBBY_ADMIN_PHONE_E164=+962799999999
SPORTS_LOBBY_ADMIN_PASSWORD=Admin123!

The bootstrap can create or update the admin account and add the ADMIN role.
It should be used only for local/dev setup.

IMPORTANT CURRENT NOTES
- The backend is authoritative for roles, permissions, publishing, capacity, and prices.
- The mobile app must never be trusted for vendor approval, lobby capacity, or reservation success.
- Real SMS is not active unless Twilio env variables are configured.
- Vendor approval is required before publishing public lobbies.
- If a lobby publish fails with "court does not support this sport", make sure the selected court has that sport enabled.
- If mobile cannot reach backend on Android, use 10.0.2.2 instead of localhost. The API client already does this.
