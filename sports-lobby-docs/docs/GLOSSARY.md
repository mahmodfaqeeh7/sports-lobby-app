# Domain Glossary

Use these terms consistently in product, code, APIs, and database.

**Player / Consumer**: End user who reserves a seat to play.

**Vendor**: Business/operator account that manages one or more physical venues.

**Venue**: Physical sports facility/location.

**Court**: Specific playable surface/field inside a venue. Use `court` as the generic code term even for football fields unless product UI localizes it differently.

**Sport**: Data-driven activity such as football, basketball, volleyball, tennis, padel.

**Lobby**: Scheduled sports session on a specific court with time, capacity, price, and joinable player seats.

**Reservation**: A player's booked seat in a lobby.

**Attendance**: Outcome after a reservation: attended, no-show, excused, etc.

**Verification**: Admin review that allows a vendor to operate/publish.

**Restriction**: Temporary capability limitation such as blocking new reservations or vendor publishing.

**Strike**: Recorded policy violation signal that may contribute to restrictions.

**Payment**: Attempt/record of transferring money for a reservation.

**Refund**: Return of paid money.

**Wallet/Ledger**: Auditable record of credits, debits, penalties, adjustments and obligations; not merely a mutable balance.

**GMV**: Gross merchandise/booking value passing through the marketplace, if/when online commerce is tracked.
