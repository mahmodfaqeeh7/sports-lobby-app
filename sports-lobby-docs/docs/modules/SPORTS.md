# Module: Sports

## Purpose
Provide a dynamic admin-managed catalog of sports.

## Requirements
- Admin create/update/activate/deactivate sport.
- Stable code + display name.
- Optional icon/image.
- Courts and lobbies reference sport IDs.

## Rules
- Deactivating a sport blocks new usage but should not corrupt historical lobbies/reservations.
- Never hardcode known sports into core business conditions.

## Initial examples
Football, basketball, volleyball, tennis, padel, badminton.
