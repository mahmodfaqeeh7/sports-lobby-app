# Module: Reviews, Reports and Moderation

## Reviews
Initial recommendation:
- venue reviews only after eligible completed reservation;
- rating + optional text;
- moderation status;
- prevent unrelated/fake reviews through reservation eligibility.

Public player-to-player ratings are future scope.

## Reports
Targets:
- player;
- vendor;
- venue;
- lobby;
- review;
- other supported content.

Flow:
OPEN -> UNDER_REVIEW -> ACTION_TAKEN/DISMISSED -> CLOSED.

## Admin actions
- warning;
- remove review/content;
- strike;
- temporary restriction;
- vendor publishing restriction;
- account/vendor suspension.

## Audit
Every consequential moderation action records actor, reason, target, timestamp, and relevant case.
