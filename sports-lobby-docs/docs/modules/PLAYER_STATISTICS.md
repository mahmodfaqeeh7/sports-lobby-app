# Module: Player Statistics

## Initial statistics
- games joined;
- games completed;
- sports played;
- attendance percentage;
- no-show count;
- cancellation count;
- favorite/most-played sport;
- most visited venues.

## Rules
- Derived from authoritative history.
- Do not let player directly edit statistics.
- Public visibility is a separate privacy/product decision.

## Future
- sport-specific performance stats;
- rankings;
- achievements;
- leaderboards;
- professional/scouting profile.

Do not design advanced competitive scoring until reliable input data exists.
