# Product Roadmap

This roadmap is a sequencing recommendation, not a fixed deadline plan.

## Version 0 - Foundation

- Repo setup.
- React Native app shell/theme/navigation.
- Spring Boot modular structure.
- PostgreSQL migrations.
- Auth/session foundations.
- CI checks.
- S3 abstraction.
- API/error conventions.

## Version 1 - Marketplace Core

- Player signup/login/OTP/Google.
- Vendor signup and verification.
- Admin vendor approval.
- Dynamic sports.
- Venue/court management.
- Venue images/location/opening hours.
- Lobby creation/publish/discovery/details.
- Transactional seat reservation.
- Reservation history.
- Basic cancellation rules.
- Push/in-app notifications.
- Cash payment status.

## Version 1.1 - Reliability and Operations

- Attendance/no-show.
- Strike/restriction system.
- Vendor cancellation enforcement.
- Alternative recommendations after cancellation.
- Better vendor dashboard.
- Reports/moderation.
- Audit logs.
- Stronger observability.

## Version 1.2 - Online Payments

- Payment provider integration.
- Card/Apple Pay depending on provider/market support.
- Refund automation.
- Reconciliation.
- Ledger/outstanding balances.

## Version 1.3 - Discovery and Retention

- Favorites.
- Personalized deterministic recommendations.
- Better search/ranking.
- Venue reviews.
- Basic player stats.
- Waitlist.

## Version 2 - Social and Competition

- Friends/following.
- Group/lobby chat.
- Teams.
- Tournaments/brackets.
- Rankings/leaderboards.
- Advanced player statistics.
- Achievements.

## Version 3 - Commercial/International Expansion

- Multi-language.
- Multi-currency.
- Country-specific policies.
- Vendor subscriptions/commission model.
- Promotions/featured placement.
- Larger-scale analytics.
